**Bookstore — ASP.NET Core MVC Web Application** &nbsp;·&nbsp; *Independent project* &nbsp;·&nbsp; [Source code](https://github.com/zidanalhilali/Bookstore)
<br><sub>Book catalog web app with full CRUD for books and authors, image upload, search, and validation</sub>

- Built with ASP.NET Core MVC and Entity Framework Core (Code-First, Migrations) on SQL Server, with a one-to-many relationship between authors and books.
